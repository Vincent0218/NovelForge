# NovelForge 📖

> **繁體小說智慧爬蟲與電子書 (EPUB/TXT) 生成工具**  
> 支援 Cloudflare TLS 指紋突破、Web Font 字體反爬解密、Unicode 深度廣告清洗、增量追更與 EPUB/TXT 雙格式輸出。


---

## 🌟 核心特色

- **多小說全本抓取**：
  - 《我都元嬰期了，你跟我說開學？》全書 **2,509 章**（16.91 MB TXT / 8.97 MB EPUB）
  - 《聚寶仙盆》全書 **2,059 章**（14.30 MB TXT / 7.17 MB EPUB）
- **Web Font 自定義字體反爬蟲解密**：內建字形輪廓比對演算法，100% 精準還原 timotxt 等網站隨機混淆的 149 個高頻漢字，內文絕無韓文或亂碼。
- **Cloudflare TLS 防護突破**：使用 `curl-cffi` 模擬真實瀏覽器 TLS 指紋（Chrome 120），穩定穿透 WAF 防護與 403 阻擋。
- **斷點續傳與獨立快取**：依書籍 ID 分離快取目錄（`data/chapters/`、`data/0104529116/`），中斷重啟自動秒級略過已下載章節，支援增量追更。
- **智慧內文深度清洗**：
  - **廣告與浮水印**：過濾廣告代碼（`loadAdv`、`<script>`、`clickforceads`）、Unicode 圈號/雙線/變音符號域名引流字樣。
  - **章節標題去重**：自動剝離正文開頭重複出現的章節名稱。
  - **文末作者留言過濾**：自動清理作者文末求票、求打賞、請假等碎碎念，並具備**嚴格三層防誤刪機制**（引號對話絕對保留）。
  - **標準排版**：統一格式化為繁體中文全形縮排段落（`　　`）。
- **標準雙格式產出**：
  - **EPUB**：包含書籍 Metadata（書名、作者、語言）、樣式表（CSS）、目錄索引（TOC / NCX / Nav），完美相容各電子書閱讀器。
  - **TXT**：整本單一文字檔案，清楚標註章節大綱與分隔線。
- **強健重試與限流應變**：具備 HTTP 429 智慧指數退避演算法與多輪遺漏章節自動補抓機制。
- **乾淨的現代 Python 環境**：嚴格使用 `uv` 管理獨立虛擬環境（`.venv`），不污染系統環境。

- Python 3.11+
- [uv](https://github.com/astral-sh/uv) 套件管理工具

### 2. 安裝與設定環境
在專案根目錄下執行以下指令自動建立虛擬環境並安裝依賴：

## 🔄 追更連載與增量抓取（如何抓取最新章節）

如果小說作者發布了新的章節，您**不需要重新下載整部小說**，只需再次執行對應小說的執行指令：

```bash
# 追更《我都元嬰期了，你跟我說開學？》
uv run python -m src.main

# 追更《聚寶仙盆》
uv run python -m src.download_timotxt
```

### 運作原理：
1. **自動刷新目錄**：主程式每次執行時預設會向網站請求最新的章節目錄，取得新增的章節列表。
2. **智慧增量下載**：程式會逐一檢查本機快取資料夾。先前已經下載完成的數千個章節會**在 1 秒內快速略過**，爬蟲**只會下載新增的最新章節**。
3. **自動重新封裝**：下載完成後，會自動將全書（舊章節 + 最新章節）重新合成並覆蓋產出最新的 `.epub` 與 `.txt` 檔案。

### 常用命令參數：
- **一般追更（預設）**：自動線上檢查最新章節並增量下載
- **自訂並行線程數**：加入 `--workers 8`
- **離線重新封裝**：加入 `--offline`（僅依據本機快取重新產出 TXT/EPUB）
