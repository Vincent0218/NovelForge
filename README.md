# 小說抓取與電子書 (EPUB/TXT) 生成工具

針對繁體小說網站（台灣小說網 twkan.com）開發的高效、具備防禦機制與斷點續傳功能的小說爬蟲與電子書（EPUB/TXT）合成工具。

---

## 🌟 核心特色

- **完整全書抓取**：已完整抓取《我都元嬰期了，你跟我說開學？》全書共 **2,509 章**（17 MB TXT / 9 MB EPUB）。
- **Cloudflare 防護突破**：使用 `curl-cffi` 模擬真實瀏覽器 TLS 指紋（Chrome 120），穩定穿透 WAF 防護與 403 阻擋。
- **斷點續傳與快取機制**：單章即時以 JSON 快取儲存於 `data/chapters/`，中斷重啟自動跳過已完成章節，支援增量更新。
- **智慧內文清洗**：自動過濾廣告代碼（`loadAdv`、`<script>`）、網站浮水印（例如網址引流字樣）以及多餘空白，並排版為標準繁體中文全形縮排段落。
- **標準雙格式產出**：
  - **EPUB**：包含書籍 Metadata（書名、作者、語言）、樣式表（CSS）、目錄索引（TOC / NCX / Nav），完美相容各電子書閱讀器。
  - **TXT**：整本單一文字檔案，清楚標註章節大綱與分隔線。
- **強健重試與限流應變**：具備 HTTP 429 智慧指數退避演算法與多輪遺漏章節自動補抓機制。
- **乾淨的現代 Python 環境**：嚴格使用 `uv` 管理獨立虛擬環境（`.venv`），不污染系統環境。

## 🚀 快速上手

### 1. 環境需求
- Python 3.11+
- [uv](https://github.com/astral-sh/uv) 套件管理工具

### 2. 安裝與設定環境
在專案根目錄下執行以下指令自動建立虛擬環境並安裝依賴：

```bash
uv sync
```

### 3. 執行小說抓取與轉檔
直接透過 `uv` 執行主程式：

```bash
uv run python -m src.main
```

程式將自動執行：
1. 連線網站取得並解析最新章節目錄
2. 多線程下載章節並寫入快取（已快取的章節自動跳過）
3. 檢查並自動補抓遺漏章節
4. 生成 `output/我都元嬰期了，你跟我說開學？.txt`
5. 封裝 `output/我都元嬰期了，你跟我說開學？.epub`

## 🔄 追更連載與增量抓取（如何抓取最新章節）

如果小說作者發布了新的章節，您**不需要重新下載整部小說**，只需再次執行相同指令即可：

```bash
uv run python -m src.main
```

### 運作原理：
1. **自動刷新目錄**：主程式每次執行時預設會向網站請求最新的章節目錄，取得新增的章節列表（例如新發布的第 2510、2511 章）。
2. **智慧增量下載**：程式會逐一檢查本機快取資料夾 `data/chapters/`。先前已經下載完成的 2,509 個章節會**直接秒級略過**，爬蟲**只會下載新增的最新章節**。
3. **自動重新封裝**：下載完成後，會自動將全書（舊章節 + 最新章節）重新合成並覆蓋產出最新的 `.epub` 與 `.txt` 檔案。

### 常用命令參數：
- **一般追更（預設）**：`uv run python -m src.main`
- **自訂並行線程數**：`uv run python -m src.main --workers 6`
- **離線重新封裝（不連網檢查新章節，僅依據本機快取重新產出檔案）**：`uv run python -m src.main --offline`

## ⚙️ 客製化設定

您可在 `src/config.py` 中微調爬蟲設定：

- `DEFAULT_WORKERS`: 並行下載線程數（預設 `4`，建議 3~6 之間以避免伺服器頻繁 429）
- `REQUEST_TIMEOUT`: 單次請求逾時時間（秒）
- `MAX_RETRIES`: 單章失敗重試次數
- `BOOK_ID` / `BOOK_TITLE` / `BOOK_AUTHOR`: 目標小說資訊
